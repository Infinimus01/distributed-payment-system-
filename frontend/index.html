🔑 Key Design Decisions
⚡ Idempotency — Redis + DB double-check prevents duplicate payments. Unique constraint on idempotency_key.
🔒 Optimistic Locking — version column on wallets prevents concurrent balance corruption.
📒 Ledger Pattern — Append-only ledger entries for full audit trail and balance reconciliation.
♻️ Retry with Backoff — Exponential backoff (1s, 2s) for transient wallet service failures. Non-retryable errors fail fast.
🛡️ Rate Limiting — Redis sliding-window per API key. Tier-based limits (100 vs 1000 req/min).
🐳 Docker-first — Multi-stage builds, health checks, and db-init container ensure zero-config startup.
